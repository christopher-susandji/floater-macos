Requirements

  • macOS 26.5 or later.

Using Floater

  • Enter a title and a time, then choose Create Timer.
  • Each timer opens as a floating panel that stays above your other windows.
  • Run up to five timers at once, each with its own title and duration.
  • Pick a Classic or Vintage look, and choose a chime for when time is up.

Using a timer in Keynote

  1. Open Floater Settings and enable Floater as Camera Input.
  2. In Keynote, choose Insert > Live Video.
  3. Select Floater from the list of cameras.

Tip: set the broadcast background color in Settings to match your slide.
